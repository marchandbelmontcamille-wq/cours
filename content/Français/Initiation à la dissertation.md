Le sujet de dissertation peut prendre 3 formes : citation/affirmation/question sur l'œuvre étudiée. Il s'agit de confronter le jugement porté sur l'œuvre
-> Analysez le sujet : soulignez les mots-clés et définissez les
-> Proposez un plan dialectique : I : Oui 2 : Mais
-> arguments + exemples
